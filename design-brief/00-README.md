# Dossier de briefing design — Raphaëlo Pizza

> **À lire en premier.** Ce dossier contient tout ce dont « claude design » a besoin pour
> refaire entièrement le design de la landing page Raphaëlo Pizza : meilleur,
> plus awwwards, mieux animé, plus adapté à une pizzeria artisanale.

## Comment utiliser ce dossier

1. Donne **l'intégralité du dossier** à claude design (les fichiers `.md` + le dossier `assets/`).
2. Le fichier **`10-brief-claude-design.md`** est le prompt prêt à coller : c'est le point de départ.
3. Les autres fichiers sont les **annexes de référence** que claude design consultera au besoin.

## Décisions déjà arrêtées par le client (non négociables)

- **Direction artistique** : laisser claude design proposer 2-3 pistes et recommander → voir `06`.
- **Logo** : conservé **tel quel** (y compris le bonnet). Ne pas le redessiner. → voir `04`.
- **Images** : réutiliser les **liens d'images de pizza déjà présents dans le projet** (listés dans `04`).
- **Périmètre** : **une seule landing page**, mais enrichie (plus de sections, meilleur storytelling).

## Résumé en une phrase

> Refaire la landing page d'une pizzeria artisanale camerounaise (Yaoundé & Douala)
> qui prend commande via WhatsApp — en visant un niveau de finition « awwwards »,
> avec un motion design soigné et une expérience plus appétissante et mémorable,
> tout en gardant le logo et les visuels existants.
